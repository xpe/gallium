# Gallium (row staggered)

Contains the [Gallium keyboard layout][1] (row staggered variant).

[1]: https://github.com/GalileoBlues/Gallium/

## macOS

To install for all users, copy the `.bundle` to `/Library/Keyboard Layouts`.

Don't forget to escape spaces in directories:

```sh
cp Gallium_r5.bundle /Library/Keyboard\ Layouts
```
